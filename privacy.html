Privacy policy

Clip Pipeline — last updated 9 November 2026

Who this covers

Clip Pipeline is a private application operated by one person, for their own use. It has no end users and no sign-up. "You" in this policy means the operator of the tool; there is nobody else whose data it handles.

What the application accesses

  • Google / YouTube: a single OAuth scope, youtube.upload. It is used only to upload video files to the operator's own channel. The application cannot read the channel's analytics, comments, subscribers or any other Google account data.
  • Twitch: public clip metadata and clip video files for a short list of channels whose terms permit clipping.

Nothing else is requested, and no permission is used for any purpose other than the one described above.

What is stored, and where

  • The Google OAuth refresh token is stored in a configuration file on the operator's own machine, in a directory that is not publicly served.
  • No data is stored on a server belonging to this application. There is no backend service, no hosted database and no account system.
  • Downloaded clips, transcripts and rendered videos exist only on the operator's own hardware and are deleted or moved to an archive folder at the operator's discretion.

What is never done

  • No data is sold, rented, or shared with third parties.
  • No data is used to train machine-learning models.
  • No advertising, profiling or analytics of any kind.
  • Nothing relating to any other person's Google or Twitch account is accessed.

Cookies and tracking

This website sets no cookies, loads no third-party scripts and contains no analytics or tracking of any kind. It is a static page.

Retention and removal

Access can be revoked at any time by the operator from their Google Account permissions page (Security → Third-party apps with account access). Revoking it immediately invalidates the stored refresh token; the application then simply stops working until re-authorised.

Changes

If this policy changes, the date at the top of this page changes with it.
